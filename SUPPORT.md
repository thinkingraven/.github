# Getting help

- **Bugs and feature requests:** open an issue on the project's repository, using its issue forms.
- **Security problems:** see [SECURITY.md](SECURITY.md); please don't open a public issue.
- **Everything else:** message us on [X](https://x.com/thinkingravenai) or [LinkedIn](https://www.linkedin.com/company/thinking-raven-ai/).

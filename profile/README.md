<a href="https://github.com/thinkingraven"><img src="https://raw.githubusercontent.com/thinkingraven/.github/main/profile/assets/banner.png" width="100%" alt="thinking raven. Open-source tools for AI agents. Tools for teams building with AI agents: find the skills your teams keep rebuilding, review what they can do, share the good ones."></a>

Teams everywhere are writing the same agent skills, rules and MCP configs, in every repo and for every tool, and nobody checks what they're allowed to do. We're building the tools to **see them, review them and share the good ones**, in the open.

<a href="https://github.com/thinkingraven/rookery"><img src="https://raw.githubusercontent.com/thinkingraven/.github/main/profile/assets/rookery.png" width="100%" alt="rookery: find every AI agent skill in your repos, spot the duplicates, catch the risky ones. A CLI and GitHub Action for Claude Code, Codex, Cursor, Copilot, Gemini, Windsurf, MCP and skillshare."></a>

<a href="https://github.com/thinkingraven/roost"><img src="https://raw.githubusercontent.com/thinkingraven/.github/main/profile/assets/roost.png" width="100%" alt="roost: see what your AI agents actually use, keep what works, retire the rest. A CLI that runs locally on Claude Code, Codex and Gemini CLI session logs: skills, subagents, MCP servers and tokens."></a>

**Now:** [rookery](https://github.com/thinkingraven/rookery), an inventory and security check for every agent skill across your repos (`npx @thinkingraven/rookery scan .`), and [roost](https://github.com/thinkingraven/roost), which shows what your agents actually use: skills, subagents, MCP servers and tokens, read locally from their session logs.<br>
**Next:** a registry to publish, review and measure the skills worth sharing across a company.

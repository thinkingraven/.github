# Contributing

Thanks for helping. Each project's own `CONTRIBUTING.md` explains its setup and conventions; where a project doesn't have one, these basics apply:

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Keep pull requests focused, with tests where it makes sense.
3. Never include secrets, real customer data or anyone's personal information. See [PUBLIC-REPOS.md](PUBLIC-REPOS.md).
4. By contributing, you agree your contribution is licensed under the project's licence.

Please follow the [code of conduct](CODE_OF_CONDUCT.md).

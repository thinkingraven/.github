Open-source tools for AI agents. Sharpen, measure and trust your agent skills: find the weak spots, see which skills get used and help, catch the risky ones. Works with Claude Code, Codex, Cursor, Copilot, Gemini and MCP."></a>

Teams everywhere are writing agent skills, rules and MCP configs, in every repo and for every tool, and almost nobody can say which ones are any good, which ones get used or what they're allowed to do. We're building the tools to **sharpen them, measure them and trust them**, in the open.

<a href="https://github.com/thinkingraven/rookery"><img src="https://raw.githubusercontent.com/thinkingraven/.github/main/profile/assets/rookery.png" width="100%" alt="rookery: find every AI agent skill in your repos, spot the duplicates, catch the risky ones. A CLI and GitHub Action for Claude Code, Codex, Cursor, Copilot, Gemini, Windsurf, MCP and skillshare."></a>

<a href="https://github.com/thinkingraven/roost"><img src="https://raw.githubusercontent.com/thinkingraven/.github/main/profile/assets/roost.png" width="100%" alt="roost: see what your AI agents actually use, keep what works, retire the rest. A CLI that runs locally on Claude Code, Codex and Gemini CLI session logs: skills, subagents, MCP servers and tokens."></a>

**Now:** [rookery](https://github.com/thinkingraven/rookery), which finds every agent skill across your repos, spots the duplicates and catches the risky ones (`npx @thinkingraven/rookery scan .`), and [roost](https://github.com/thinkingraven/roost), which shows what your agents actually use: skills, subagents, MCP servers and tokens, read locally from their session logs.<br>
**Next:** seeing which skills actually help your teams, not just which ones run.

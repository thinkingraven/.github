# Security policy

This policy covers every Thinking Raven repository that doesn't have its own `SECURITY.md`.

## Reporting a vulnerability

Report privately, never in a public issue: open a private advisory on the affected repository (**Security → Report a vulnerability**).

We aim to reply within 3 working days and to fix or mitigate within 30 days, and we credit reporters in release notes unless you'd rather we didn't.

## Leaked secrets

If you find a credential in one of our repositories, please report it the same way. We rotate first and clean up history second.
